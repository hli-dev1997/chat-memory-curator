# 优先选择轻量级小模型规则

## 核心要求
1. 在配置或选择 AI 大语言模型（Text Model）时，**必须优先选择轻量级、低参数量、响应快、节约 Token 的小模型**（如 `7B` ~ `8B` 级别的轻量模型，例 `deepseek-r1-distill-qwen-7b`、`qwen3-8b`、`qwen-mt-flash` 等）。
2. **严禁** 优先使用大型超强模型（如 `qwen-max`、`qwen-long` 等高消耗模型），除非用户显式要求。
3. 当某个模型免费额度用尽时，从枚举中替换下一个可用模型时，也必须优先在轻量小模型中挑选，最大程度帮用户节省 Token 额度。
